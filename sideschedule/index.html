How it works

Always there, so you never have to switch to it.

1

It reserves the space

Apple never gave regular apps a way to claim screen space like the Dock can. So SideSchedule fakes it: any window that tries to slide under the sidebar gets nudged back out. You’ll never notice it happening.

Your windows live here
Dock Menu bar SideSchedule

Other windows physically can’t cover the strip — the space is reserved, not floated on top.

2

One permission does it

Accessibility, under System Settings → Privacy & Security. It’s the only thing SideSchedule asks for besides Calendar access — and the reason the whole trick works.

System Settings Privacy & Security Accessibility

One toggle, one time. No background daemons and no kernel extensions.

3

Notes become files

Because the sidebar is always there, it’s the one place you can type notes without leaving the call. Every note saves as a standalone .md file into a folder you pick.

---
title:    "Weekly sync"
event_date: 2026-09-04
event_time: 14:00–14:30
calendar: Work
tags:     [meeting]
source:   sideschedule
---

Typed during the call. Read by Obsidian, Logseq, or any local AI tool.

Plain Markdown with YAML frontmatter — no glue code needed.

Questions

The ones that actually come up.

Does it work with my calendar?

SideSchedule reads from Apple Calendar (EventKit), so anything Apple Calendar can see — iCloud, Google, Exchange, CalDAV — shows up in the sidebar. No extra sync, no account.

Why does it need Accessibility access?

That’s the only way macOS lets an app keep other windows from sliding under the sidebar. The Dock gets its reserved strip from the system itself; a regular app has no such API, so Accessibility is the only route left. SideSchedule never reads window content — it only repositions frames.

What happens after the 14-day trial?

The sidebar stops appearing and the app opens to the activation window instead. Nothing is deleted: your notes, settings and exported .md files all stay exactly where they are, and the sidebar returns the moment you enter a key. No reinstall needed.

Is my data sent anywhere?

The app: no. Your calendar events and notes stay on your Mac. The only network calls are license validation (Lemon Squeezy) and update checks (GitHub). No analytics, no tracking, no telemetry. This website counts visits with GoatCounter, without cookies, and loads no other third-party scripts; if you arrive through a partner’s link, the partner’s ID is added to the Buy links so they get credited — details in the privacy policy.

Can I get a refund?

Lemon Squeezy handles payments as merchant of record. If something’s genuinely broken, write to hello@didact.digital and we’ll figure it out — but the 14-day trial exists so you can be sure before you pay.

Does it work on multiple monitors?

Yes. You pick which display the sidebar lives on, and it follows that screen. If you unplug the monitor, it moves to the next one automatically.

How many Macs does one licence cover?

Two. Activate on both — a desktop and a laptop, say. “Deactivate this Mac” in Preferences frees the slot again, so replacing a machine doesn’t cost you an activation.

Does it work with fullscreen apps?

Not properly yet. A native-fullscreen window takes the whole screen and the sidebar ends up drawn over it instead of shrinking it. That one sits on the roadmap under Exploring. Everywhere else, including a window you have manually dragged to full size, the reserved strip holds.

What happens to my notes if I stop using it?

Nothing. They are plain .md files in the folder you picked, readable by Obsidian, Logseq or any text editor. There is no export step because there is nothing to export from.
