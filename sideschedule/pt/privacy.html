Política de privacidade

Última atualização: 12 de outubro de 2026

O SideSchedule é uma aplicação para macOS desenvolvida por Ingo Jurz, Graz, Áustria. Esta página explica que dados a aplicação toca, o que sai do seu Mac e o que nunca sai.

A versão curta

  • Os seus eventos e notas ficam no seu Mac. Nunca são enviados para lado nenhum.
  • A aplicação não tem análises, rastreamento, SDK de relatórios de falhas nem publicidade.
  • As únicas ligações de rede da aplicação: validação da licença (Lemon Squeezy) e verificação de atualizações (Sparkle, via GitHub).
  • Este site conta as visitas com o GoatCounter, sem cookies, e não carrega outros scripts de terceiros. O ID de um parceiro vindo de um link de parceiro só fica no seu navegador se aceitar — veja «Este site» mais abaixo.

Este site

Contamos as visitas com o GoatCounter (veja «Estatísticas de visitas» mais abaixo); além desse script, este site não carrega scripts de terceiros. Se chegar através do link de um parceiro (um URL com <code>?aff=</code>), juntamos o ID do parceiro aos links de compra dessa página, para que a Lemon Squeezy, o nosso prestador de pagamentos, possa creditar o parceiro se comprar. Ler o ID do link não guarda nada no seu dispositivo. Se também aceitar no aviso, guardamos o ID durante 60 dias no armazenamento local do navegador, para que o parceiro seja creditado também por uma compra posterior. No primeiro arranque, a app abre uma única vez uma página de boas-vindas em didact.digital. Se tinha aceitado, essa página entrega o ID à app, que o guarda no Porta-chaves do macOS e o junta apenas ao seu link de compra. Um clique num link de compra leva-o à Lemon Squeezy, onde se aplica a política de privacidade dela. A base jurídica para guardar o ID é o seu consentimento (art. 6.º, n.º 1, alínea a, RGPD; § 165, n.º 3, TKG 2021). Pode retirá-lo a qualquer momento com o botão abaixo, que remove o ID guardado do navegador. Para o remover também da app, escreva para <a href="mailto:hello@didact.digital">hello@didact.digital</a>. A própria app nunca carrega um script de rastreio.

O script é carregado dos servidores da Lemon Squeezy; a política de privacidade deles aplica-se a esse pedido. A aplicação nunca o carrega.

Estatísticas de visitas

Este site conta as visitas com o GoatCounter, um serviço de estatísticas que funciona sem cookies. Assim vemos que páginas são lidas, que links trazem visitantes e quantas vezes os botões de download e de compra são clicados. Os dados não servem para publicidade nem para criar perfis de pessoas. Quando abre uma página, o seu navegador envia ao GoatCounter o endereço da página, o site de origem, as etiquetas de campanha do link (por exemplo utm_source), o navegador e o tamanho do ecrã, e a sua localização aproximada. Segundo o GoatCounter, não são guardados endereços IP nem cadeias de user-agent e não são definidos cookies; não é reconhecido entre visitas nem entre sites. Um clique num link de download ou de compra é contado como um evento com nome fixo, sem dados sobre si. O GoatCounter é gerido por Martin Tournoij (Irlanda); os servidores estão na Hetzner Online GmbH, na Finlândia e na Alemanha. A base jurídica é o nosso interesse legítimo em perceber como o site é utilizado (art. 6.º, n.º 1, al. f) do RGPD). Pode opor-se a qualquer momento: hello@didact.digital. Bloquear o script no navegador também funciona, e o site continua totalmente utilizável. As apps são separadas: não contêm análises e não enviam dados de utilização.

Dados do calendário

O SideSchedule lê os seus calendários através do framework EventKit da Apple para mostrar o seu dia. Se criar, renomear, reagendar ou apagar eventos, essas alterações são escritas de volta no Apple Calendar. As notas que escreve no SideSchedule ficam guardadas localmente no seu Mac (e opcionalmente duplicadas como ficheiros Markdown numa pasta à sua escolha, ou na descrição do evento no Apple Calendar se ativar essa opção). Nada disto é transmitido a nós nem a terceiros.

Acesso à Acessibilidade

Se ativar «Manter as janelas fora da barra», o SideSchedule usa a API de Acessibilidade do macOS para observar e reposicionar as janelas da aplicação em primeiro plano, para que não deslizem para baixo da barra lateral. Tudo acontece no seu Mac. Nenhum título de janela, nome de aplicação ou dado de utilização é recolhido ou transmitido.

Ativação e validação da licença

Quando introduz uma chave de licença, o SideSchedule contacta a API da Lemon Squeezy (api.lemonsqueezy.com) por HTTPS para a ativar e validar periodicamente. O pedido inclui a sua chave e o nome de host do seu Mac (usado como etiqueta de ativação para reconhecer o dispositivo no seu portal de cliente da Lemon Squeezy). A chave fica guardada no Porta-chaves do macOS, não em preferências em texto simples.

Atualizações

O SideSchedule verifica atualizações através do framework Sparkle, que descarrega um ficheiro appcast alojado no GitHub (github.com). O GitHub pode registar o seu endereço IP ao servir esse ficheiro, segundo a sua própria política de privacidade. Os downloads de atualizações são assinados e verificados com uma assinatura EdDSA antes da instalação.

Relatórios de diagnóstico

Pode enviar manualmente um relatório de diagnóstico por e-mail a partir da barra de menus ou das Preferências. Sempre por iniciativa sua: a aplicação reúne registos recentes, relatórios de falhas e informações básicas do sistema num rascunho que pode rever, editar ou apagar antes de enviar. Estes ficheiros podem conter caminhos locais e o nome de host do seu Mac. Nada é enviado automaticamente.

O que nunca recolhemos

  • Nenhuma conta nem registo
  • Nenhuma análise nem estatística de utilização
  • Nenhum identificador de publicidade
  • Nenhum dado de falhas, a menos que o envie por e-mail
  • Nenhum conteúdo de calendário, nota ou informação de janelas

Pagamento

As compras são processadas pela Lemon Squeezy como comerciante oficial. Os seus dados de pagamento são geridos inteiramente pela Lemon Squeezy e nunca tocam nesta aplicação nem nos nossos sistemas. Detalhes: política de privacidade da Lemon Squeezy
