Politique de confidentialité

Dernière mise à jour : 12 octobre 2026

SideSchedule est une application macOS développée par Ingo Jurz, Graz, Autriche. Cette page explique quelles données l’application touche, ce qui quitte votre Mac et ce qui n’en sort jamais.

En bref

  • Vos événements et vos notes restent sur votre Mac. Ils ne sont jamais téléversés.
  • L’application n’a ni analyse, ni suivi, ni SDK de rapport de plantage, ni publicité.
  • Les seuls appels réseau de l’application : validation de licence (Lemon Squeezy) et vérification des mises à jour (Sparkle, via GitHub).
  • Ce site compte les visites avec GoatCounter, sans cookies, et ne charge aucun autre script tiers. L’identifiant d’un partenaire issu d’un lien partenaire ne reste dans votre navigateur que si vous l’acceptez — voir « Ce site web » plus bas.

Ce site web

Nous comptons les visites avec GoatCounter (voir « Statistiques de visite » plus bas) ; hormis ce script, ce site ne charge aucun script tiers. Si vous arrivez par le lien d'un partenaire (une URL contenant <code>?aff=</code>), nous ajoutons l'identifiant du partenaire aux liens d'achat de cette page, afin que Lemon Squeezy, notre prestataire de paiement, puisse créditer le partenaire si vous achetez. Lire l'identifiant dans le lien ne stocke rien sur votre appareil. Si vous acceptez en plus dans le bandeau, nous conservons l'identifiant 60 jours dans le stockage local de votre navigateur, afin que le partenaire soit aussi crédité en cas d'achat ultérieur. Au premier lancement, l'app ouvre une seule fois une page de bienvenue sur didact.digital. Si vous aviez accepté, cette page transmet l'identifiant à l'app, qui l'enregistre dans le trousseau macOS et l'ajoute uniquement à son lien d'achat. Un clic sur un lien d'achat vous mène chez Lemon Squeezy, dont la politique de confidentialité s'applique alors. La base juridique de la conservation de l'identifiant est votre consentement (art. 6, par. 1, point a, RGPD ; § 165, al. 3, TKG 2021). Vous pouvez le retirer à tout moment avec le bouton ci-dessous, qui supprime l'identifiant enregistré de votre navigateur. Pour le faire supprimer aussi de l'app, écrivez à <a href="mailto:hello@didact.digital">hello@didact.digital</a>. L'app elle-même ne charge jamais de script de suivi.

Le script est chargé depuis les serveurs de Lemon Squeezy ; leur politique de confidentialité s’applique à cette requête. L’application ne le charge jamais.

Statistiques de visite

Ce site compte les visites avec GoatCounter, un service de statistiques qui fonctionne sans cookies. Nous voyons ainsi quelles pages sont lues, quels liens amènent les visiteurs et combien de fois les boutons de téléchargement et d’achat sont cliqués. Ces données ne servent ni à la publicité ni à établir des profils de personnes. Quand vous ouvrez une page, votre navigateur envoie à GoatCounter l’adresse de la page, le site de provenance, les paramètres de campagne du lien (par exemple utm_source), le navigateur et la taille d’écran ainsi que votre localisation approximative. Selon GoatCounter, ni adresses IP ni chaînes user-agent ne sont enregistrées et aucun cookie n’est déposé ; vous n’êtes reconnu ni d’une visite à l’autre ni d’un site à l’autre. Un clic sur un lien de téléchargement ou d’achat est compté comme un événement portant un nom fixe, sans aucune information sur vous. GoatCounter est exploité par Martin Tournoij (Irlande) ; ses serveurs se trouvent chez Hetzner Online GmbH en Finlande et en Allemagne. La base juridique est notre intérêt légitime à comprendre l’usage du site (art. 6, par. 1, point f du RGPD). Vous pouvez vous y opposer à tout moment : hello@didact.digital. Bloquer le script dans votre navigateur fonctionne aussi ; le site reste pleinement utilisable. Les apps sont distinctes : elles ne contiennent aucune analyse et n’envoient aucune donnée d’usage.

Données du calendrier

SideSchedule lit vos calendriers via le framework EventKit d’Apple pour afficher votre journée. Si vous créez, renommez, déplacez ou supprimez des événements, ces changements sont réécrits dans Apple Calendrier. Les notes saisies dans SideSchedule restent locales sur votre Mac (éventuellement dupliquées en fichiers Markdown dans un dossier de votre choix, ou dans la description de l’événement dans Apple Calendrier si vous activez cette option). Rien de tout cela n’est transmis à nous ni à des tiers.

Accès à l’accessibilité

Si vous activez « Garder les fenêtres hors de la barre », SideSchedule utilise l’API d’accessibilité de macOS pour observer et repositionner les fenêtres de l’application au premier plan afin qu’elles ne glissent pas sous la barre latérale. Tout se passe sur votre Mac. Aucun titre de fenêtre, nom d’application ou donnée d’usage n’est collecté ni transmis.

Activation et validation de la licence

Quand vous saisissez une clé de licence, SideSchedule contacte l’API Lemon Squeezy (api.lemonsqueezy.com) en HTTPS pour l’activer puis la valider périodiquement. La requête contient votre clé et le nom d’hôte de votre Mac (utilisé comme étiquette d’activation pour reconnaître l’appareil dans votre portail client Lemon Squeezy). La clé est stockée dans le Trousseau macOS, pas dans des préférences en clair.

Mises à jour

SideSchedule vérifie les mises à jour via le framework Sparkle, qui récupère un fichier appcast hébergé sur GitHub (github.com). GitHub peut journaliser votre adresse IP lors de cette requête ; la politique de confidentialité de GitHub s’applique. Les téléchargements sont signés et vérifiés par une signature EdDSA avant installation.

Rapports de diagnostic

Vous pouvez envoyer manuellement un rapport de diagnostic par e-mail depuis la barre de menus ou les Réglages. Toujours à votre initiative : l’application rassemble les journaux récents, les rapports de plantage et des informations système de base dans un brouillon que vous pouvez relire, modifier ou supprimer avant envoi. Ces fichiers peuvent contenir des chemins locaux et le nom d’hôte de votre Mac. Rien n’est jamais envoyé automatiquement.

Ce que nous ne collectons jamais

  • Aucun compte ni inscription
  • Aucune analyse ni statistique d’usage
  • Aucun identifiant publicitaire
  • Aucune donnée de plantage, sauf si vous l’envoyez vous-même par e-mail
  • Aucun contenu de calendrier, note ou information de fenêtre

Paiement

Les achats sont traités par Lemon Squeezy en tant que vendeur officiel. Vos données de paiement sont entièrement gérées par Lemon Squeezy et ne touchent ni l’application ni nos systèmes. Détails : politique de confidentialité de Lemon Squeezy
